# white-lab

주식회사 화이트연구소 회사 웹사이트입니다. 기술 접근성과 참여 기회를 넓히는 철학, AI와 사람의 협업을 통한 코드 재사용, BindModel·LOGIC의 역할을 소개합니다. GitHub Pages의 `/docs` 게시 방식을 사용합니다.

- [제작 계획과 진행 상태](./PLAN.md)
- [공개 웹사이트](https://bindmodel.com/)
- [웹사이트 첫 페이지](./docs/index.html)
- [로고 SVG](./docs/assets/logo.svg) · [심볼 SVG](./docs/assets/symbol.svg)

## 로컬 미리보기

별도 패키지 설치나 빌드가 필요하지 않습니다. 저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory docs
```

브라우저에서 <http://127.0.0.1:8080/>을 엽니다. 종료는 터미널에서 `Ctrl+C`를 누릅니다.

## GitHub Pages 게시

현재 게시 소스는 `main` 브랜치의 `/docs`입니다. 수정사항을 `main`에 푸시하면 GitHub Pages가 자동으로 게시합니다. 게시 설정을 다시 구성할 때는 다음과 같이 설정합니다.

1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
3. **Branch**는 `main`, 폴더는 `/docs`를 선택하고 저장합니다.
4. GitHub Actions에서 `pages build and deployment` 성공을 확인한 뒤 <https://bindmodel.com/>에서 확인합니다.

이 저장소의 사용자 도메인은 `bindmodel.com`이며 `docs/CNAME`에 기록되어 있습니다. 공개 주소는 <https://bindmodel.com/>이고 `Enforce HTTPS`를 적용했습니다. 도메인을 변경할 때는 GitHub Pages 설정과 DNS 구성을 함께 진행하고, `index.html`의 대표 URL과 `sitemap.xml`도 수정합니다. 저장소 하위 경로로 게시 방식을 바꾸는 경우 `404.html`의 루트 기준 경로도 해당 경로에 맞춰 수정합니다.

상단 주메뉴와 본문 서비스 링크는 `https://fw.bindmodel.com/`, `https://logic.bindmodel.com/`으로 연결합니다. 링크는 새 탭에서 열립니다. 본문은 회사 철학 → 개발 방식 → 보유 기술 → 사업 확장 → 신뢰 원칙 → 문의 순서입니다.

현재 제공하는 프레임워크·문서·샘플 조회와 AI 협업의 연구·개발 방향, 공유·거래의 장기 비전을 구분합니다. LOGIC 샘플을 실제 업무 구현이나 거래 상품으로 소개하지 않습니다. 책임 관련 항목은 지향하는 운영 원칙이며, 프로젝트의 계약·이용 조건에서 구체화할 기준으로 설명합니다. 확인되지 않은 성과·고객·인증·거래 실적은 추가하지 않습니다.

색상은 `styles.css` 상단의 CSS 변수에서 관리합니다. 명판의 파란색·흰색과 명함의 올리브색을 참고한 웹용 팔레트입니다. 로고는 교체 가능한 초안입니다.

상단의 달·해 아이콘 버튼으로 라이트·다크 모드를 전환합니다. 첫 방문에는 기기의 테마 설정을 따르고, 직접 선택한 모드는 브라우저에 저장하여 다음 방문과 404 페이지에서도 유지합니다. 저장소 접근이 제한된 브라우저에서도 현재 페이지의 전환은 동작합니다. JavaScript를 끈 경우에는 기기의 테마를 따르며, 인쇄할 때는 밝은 팔레트를 사용합니다. 다크 팔레트는 `:root[data-theme="dark"]`와 JavaScript 없는 환경의 미디어 쿼리에서 함께 관리합니다.

모든 화면 구성 파일은 저장소 하위 경로에서도 열리도록 상대 경로를 사용합니다. 외부 폰트·CDN·분석 도구·백엔드에 의존하지 않으며, JavaScript 없이도 소개 내용과 연락 링크를 볼 수 있습니다. LOGIC 도식은 기술을 설명하는 개념 예시입니다.

04장 사업 확장과 05장 신뢰 원칙에는 각 3장의 개념 이미지를 배치했습니다. 6초마다 자동 전환하며, 이전·다음·장면 선택·재생/정지 버튼과 좌우 방향키·Home·End·모바일 스와이프로 조작할 수 있습니다. 수동으로 이미지를 선택하면 자동 재생을 멈춥니다. 마우스를 올리거나 키보드 포커스가 들어오면 잠시 멈추고, 화면 밖이나 백그라운드 탭에서도 정지합니다. 기기의 모션 감소 설정에서는 수동 조작만 제공합니다. JavaScript를 끄거나 인쇄하면 이미지와 설명을 순서대로 볼 수 있습니다.

## 지식재산권 소개

제공된 증서를 기준으로 프로그램 저작권 등록 6건과 특허출원 2건의 명칭·번호·날짜를 반영했습니다. 저작권은 증서의 등록일, 특허는 출원일을 표시합니다. 특허 카드의 한글 제목은 기술 주제의 요약이며, 펼치면 증명원에 기재된 영문 출원 명칭을 확인할 수 있습니다.

기술 소개 아래의 ‘기술로 이어진 연구의 기록’을 펼치면 기존 등록·출원 내역을 볼 수 있습니다. 증서에 기재된 명칭·번호·날짜를 소개하는 기록이며, 법인 명의 보유를 주장하지 않습니다. 이후 등록 등 변경이 확인되면 해당 서류를 바탕으로 내용을 갱신합니다.

사용자 요청에 따라 공개 페이지에서 대표자·저작자·출원인의 개인 이름과 사업자등록번호, 상세 주소, 개업일을 제외했습니다. 회사명, 사업 분야, 전주라는 지역 소개, 회사 전화·이메일은 유지합니다. 원본 증서와 개인 식별정보는 `docs`에 포함하지 않습니다.
